# Story interactions

The action should appear with the world or the active reading before sources and methods. The control and world should agree on the selected input, and a failed source should identify which observation is still visible.

Back returns to the story’s launch point: Stories, Find, the geographic preview, the layer inspector, or the preceding story. In a connected journey, Previous view restores the earlier stop and its held reading. The return overrides below describe an additional in-story path. Keep the original source dates when connecting independent records.
